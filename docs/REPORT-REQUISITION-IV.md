# Report > ใบเบิก > ห้องเตรียมยาอาคารเภสัชกรรม

พัฒนา 23 ตุลาคม 2026 เปิดที่ `/ipd/reports/requisition-iv` ผ่าน session เดิม เป็นรายงานดูข้อมูล ไม่สร้างใบเบิก ไม่ตัดสต็อก ไม่ส่งเครื่องพิมพ์หรือ Robot

## ต้นฉบับและฟอร์ม

- ใช้ชื่อเมนู “ห้องเตรียมยาอาคารเภสัชกรรม” ตรงกับ `frmMain.Designer.vb:tsIV.Text` ไม่ใช้ชื่อ ER (OPD)
- `frmMain.vb:tsIV_Click` กำหนด StatusBT=`btnIV` และปุ่ม OK ของ `ctx/Requisition/ucUD.vb` เรียก **IV()**
- ใช้ฟอร์ม ucUD เดิม: วันที่เริ่ม/สิ้นสุดเริ่มวันนี้ ตัวเลือกส่งใบเบิกชั้น 3 (รพ.ผลิตเอง / ยาฆ่าเชื้อ), ส่งใบเบิกชั้น 4 (ค่าเริ่มต้น), ยาเสพติด และปุ่ม OK
- ใช้ฟอร์มเว็บร่วมกับใบเบิกเดิมด้วย variant=`iv` แต่แยก route/endpoint/key ทำให้สลับห้องยาแล้วไม่มีเงื่อนไขหรือ PDF ค้างข้ามห้อง
- ค้นหาเมื่อกด OK เท่านั้น เปลี่ยนวันที่หรือประเภทซ่อนรายงานเก่า/ยกเลิกคำขอเดิม ทางขวาแสดง PDF เปลี่ยนหน้า ซูม และดาวน์โหลด

## แหล่งข้อมูลและเงื่อนไข

หน้านี้ใช้ **MSSQL เท่านั้น** ตาม `clsRequisition.vb:getUsageDrugIV` ไม่มีส่วนที่ใช้ MySQL จึงไม่เพิ่มการเชื่อมต่อหรือค่าตั้ง MySQL ใหม่

- อ่าน `prescription pt LEFT JOIN ms_drug mdr ON orderitemcode` ซึ่งต่างจากใบเบิก IPD/D/C ที่ใช้ prescriptiondetail
- เงื่อนไขหลักคือ `pt.IVStatus IS NOT NULL` ไม่เปลี่ยนเป็น IVStatus=`Y` หรือกรองเฉพาะห้องยา 002
- ไม่เพิ่มเงื่อนไข departmentcode, printstatus, sendmachine, ordertype, unused, void, hold หรือเปลี่ยนไปใช้ข้อมูลจาก session เพราะ native IV() ไม่กรองสิ่งเหล่านี้
- ช่วงเวลา Asia/Bangkok ก่อน 08:00 ใช้วันก่อนวันที่เริ่ม 08:00 ถึงวันที่สิ้นสุด 07:59:00; ตั้งแต่ 08:00 ใช้วันที่เริ่ม 08:00 ถึงวันถัดจากวันที่สิ้นสุด 07:59:00 คงวินาที :00 ตาม native

| ตัวเลือก | sendStore | sendF3F4 |
| --- | --- | --- |
| รพ.ผลิตเอง | 1 | 0 |
| ยาฆ่าเชื้อ | 1 | 2 |
| ส่งใบเบิกชั้น 4 | 1 | 1 |
| ยาเสพติด | 2 | ไม่กรอง |

- รวม `SUM(CAST(pt.orderqty AS DEC(10,2)))` GROUP BY รหัส/ชื่อยาในรายการเดิม และ drugform, orderunitcode, Inventorycode, pack จาก master เรียงชื่อรายการยาตาม SQL
- ไม่แทนชื่อยาในใบสั่งด้วยชื่อ master และไม่ลดแถว master ซ้ำก่อน join เพราะจะเปลี่ยนยอดจากต้นฉบับ
- จำนวนใช้ไปใช้ VB CInt ปัดครึ่งเข้าจำนวนคู่และตรวจ Int32 ก่อนคำนวณขอเบิก `Ceiling(CInt(qty)/CInt(pack)) x pack` ถ้า pack ว่างใช้จำนวนเต็ม ถ้า pack=0 คง Infinity/NaN ตามสูตร native
- ชื่อห้อง “ห้องเตรียมยาอาคารเภสัชกรรม” เลขใบเบิก **IV** + ddMMyyyy ของวันพิมพ์ปัจจุบัน ไม่ใช้วันที่ค้นหา
- drugform ว่างเป็น “อื่นๆ” จัดกลุ่ม drugform ตาม Crystal และคงลำดับชื่อจาก SQL ภายในกลุ่ม เลขลำดับต่อเนื่อง ยอดรวมเป็นจำนวนแถว
- อ่าน query เดียวพร้อม bound parameters ต่อการค้นหา ไม่โหลด cache master/drugname ทั้งตารางที่ IV() ไม่ได้ใช้

## คอลัมน์และ PDF

- ใช้ `Report/Sendmix/crpRequisitionNew.rpt` เช่นเดียวกับ native IV() และ renderer/assets ร่วมกับใบเบิกเดิม
- A4 แนวตั้ง 595 × 842 pt ขอบ 18 pt โลโก้/ชื่อโรงพยาบาล/ที่อยู่เดิมหน้าแรก กล่องเลขใบเบิก/ชื่อห้อง/วันที่พิมพ์/หัวคอลัมน์ซ้ำทุกหน้า
- คอลัมน์เลขลำดับ, INV_Code, รหัสยา, รายการยา, min Stock (ว่าง), ใช้ไป, Rate/วัน (ว่าง), ขอเบิก, หน่วย หัวตาราง native ไม่มีชื่อเลขลำดับและรหัสยาแยกต่างหาก
- ช่องขอเบิกใช้ Pack หน่วยจาก master.orderunitcode ไม่เพิ่มค่าคงคลังหรืออัตราการใช้เอง
- ส่วนท้ายรวมจำนวนแถว และช่องลงชื่อผู้ขอเบิก/ผู้อนุมัติ/ผู้จ่าย/ผู้รับเดิม เก็บส่วนลงชื่อไว้หน้าเดียวกัน มีเลขหน้า ฝังฟอนต์ไทยและวัดข้อความก่อนแบ่งหน้า
- กรณีไม่พบข้อมูล แสดง “ระบบแจ้งเตือน / ไม่พบข้อมูล” แล้วแสดงแบบพิมพ์ว่างตาม IV() ที่ยัง SetDataSource ต่อหลังแจ้งเตือน
- ไฟล์ `IV-Requisition-Report.pdf` ใช้ Blob เดียวกับตัวอย่าง ไม่มี query ใหม่เมื่อดาวน์โหลด และ runtime ไม่ต้องติดตั้ง Crystal
