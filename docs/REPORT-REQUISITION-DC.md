- ไม่พบข้อมูลแสดง modal “ระบบแจ้งเตือน / ไม่พบข้อมูล” ปิดแล้วแสดงแบบพิมพ์ว่างตาม native

## ข้อมูลและสูตร

อ่าน MSSQL query เดียวจาก `prescriptiondetail pt LEFT JOIN ms_drug mdr ON orderitemcode` เงื่อนไขเฉพาะ D/C คือ `(pt.departmentcode='005' OR pt.departmentcode='001') AND pt.printstatus='1' AND pt.ordertype='1'` ไม่ใช้ sendmachine มาทดแทน printstatus และไม่รับห้องยาหรือวอร์ด override จาก client

| ตัวเลือก | sendStore | sendF3F4 |
| --- | --- | --- |
| รพ.ผลิตเอง | 1 | 0 |
| ยาฆ่าเชื้อ | 1 | 2 |
| ส่งใบเบิกชั้น 4 | 1 | 1 |
| ยาเสพติด | 2 | ไม่กรอง |

- ช่วงเวลา Asia/Bangkok ตาม native: ก่อน 08:00 ใช้วันก่อนวันที่เริ่ม 08:00 ถึงวันที่สิ้นสุด 07:59:00; ตั้งแต่ 08:00 ใช้วันที่เริ่ม 08:00 ถึงวันถัดจากวันที่สิ้นสุด 07:59:00
- รวม `SUM(CAST(orderqty AS DEC(10,2)))` แยกรหัส/ชื่อยาในรายการเดิม และ drugform, orderunitcode, Inventorycode, pack จาก master เรียงชื่อยาตาม SQL ไม่เปลี่ยนเป็นชื่อ master และไม่เติมเงื่อนไข void/hold/unused
- จำนวนใช้ไปใช้ VB CInt แบบปัดครึ่งเข้าจำนวนคู่ พร้อมตรวจ Int32; ขอเบิกใช้ `Ceiling(CInt(qty)/CInt(pack)) x pack` ถ้า pack ว่างใช้จำนวนเต็มที่แปลงแล้ว
- พบ pack=0 หนึ่งรายการในประเภท รพ.ผลิตเองของรอบที่ตรวจ คงข้อความ Infinity/NaN ตามสูตร Windows ไม่แก้ master หรือเดาจำนวนแพ็ก
- เลขใบเบิก `DC` + ddMMyyyy ของวันพิมพ์ปัจจุบัน ชื่อห้อง “ห้องยา D/C” ไม่ใช้วันตัวกรองเป็นเลขใบเบิก
- drugform ว่างเป็น “อื่นๆ” จัดกลุ่มตาม Crystal คงลำดับชื่อจาก SQL ภายในกลุ่ม เลขลำดับต่อเนื่อง และยอดรวมเป็นจำนวนแถว
- ไม่มี MySQL ในเส้นทางนี้ และไม่โหลด cache ms_drug/drugname ทั้งตารางที่ฟังก์ชันรายงานไม่ได้ใช้

## API และผลตรวจ

- POST `/api/reports/requisition-dc/pdf` รับเฉพาะ `{from,to,kind}` ต้องมี session ใช้ bound parameters คืน attachment/no-store พร้อม X-Report-Pages/X-Report-Rows กรณีว่างคืน PDF 1 หน้า rows=0
- Full backend regression **254/254 ผ่าน** รวม D/C 5 tests และ IPD เดิม 9 tests; targeted frontend ESLint และ production build ผ่าน
- เปรียบเทียบ SQL StringBuilder ที่อ่านจาก native กับ query เว็บครบทุกแถวทั้ง 4 ประเภท โดย `tools/check-requisition-ipd-native.cjs` โหมด `dc`: วันที่ 2026-10-21 กำหนดเวลาค้นหาเป็น 2026-10-22T02:00:00Z (หลัง 08:00 ไทย) ได้ รพ.ผลิตเอง 11 / ยาฆ่าเชื้อ 2 / ชั้น 4 189 / ยาเสพติด 3 แถว ตรงกันทั้งหมด จำนวนจริงเปลี่ยนได้ตามข้อมูลและรอบก่อน/หลัง 08:00
- PDF จำลอง 6 รายการ 1 หน้า ตรวจโลโก้ ห้องยา D/C เลข DC และช่องลงชื่อแล้ว
- PDF ทดสอบ 120 รายการ 5 หน้า พบชื่อครบ 120 และปลายชื่อยาวครบ 4 จุด ไม่มีตัวอักษรนอกกระดาษ หัว D/C ซ้ำครบทุกหน้า ตรวจภาพหน้าแรก/กลาง/สุดท้ายแล้ว
- Browser เปิดผ่านเมนูจริงได้ ค่าเริ่มต้นวันนี้/ชั้น 4 ถูกต้อง ทดสอบข้อมูลจริงวันที่ 2026-10-21: ชั้น 4 ได้ 7 หน้า และอีก 3 ประเภทได้ประเภทละ 1 หน้า เปลี่ยนเงื่อนไขแล้วซ่อน PDF เก่าจนกด OK
- วันที่ว่าง 2099-01-01 ขึ้น “ไม่พบข้อมูล” ปิดแล้วแสดง PDF ว่าง 1 หน้า สลับกลับ IPD เริ่มต้นวันนี้/ชั้น 4 ใหม่ ไม่ค้าง PDF หรือประเภทของ D/C
- พบ PDF.js รอ display animation frame ในพาเนลเบราว์เซอร์ จึงให้ตัวอย่างรายงานใช้ `intent: 'print'` เพื่อเรนเดอร์เนื้อหาสำหรับพิมพ์ให้เสร็จแม้ display frame พักอยู่ ตรวจภาพ PDF แสดงได้แล้ว ไฟล์ดาวน์โหลดและสูตรรายงานไม่เปลี่ยน
- ทดสอบรายงาน IPD เดิมหลังแก้ตัวแสดงร่วมแล้ว แสดง canvas ได้พร้อมจำนวนหน้าจาก API (รอบที่ทดสอบชั้น 4 ได้ 11 หน้า)

ทำใน local ยังไม่ได้ commit หรือ deploy ห้องยาอื่นนอกเหนือจาก IPD และ D/C ยังไม่อยู่ในงานนี้
